WHAT THIS IS
============
The scoreticker overlay does not run from the installed app. In the app,
basePage() returns https://smartcric.smartstudygrid.workers.dev/ , so every
overlay link opens the hosted web build.

That means the two new scoretickers (Cyberpunk and Luxury Dark) only appear
in the overlay once these files are published.

HOW TO PUBLISH
==============
1. Copy every file in this folder into your GitHub repo that serves
   smartcric.smartstudygrid.workers.dev - keeping the same layout:
       index.html
       js/*.js
       css/*.css
2. Commit and push.
3. Hard refresh any open overlay tab (Ctrl+Shift+R) so it picks up the new
   css/scorer.css and js/scorer.js.

Nothing else has to change. The app itself (the APK) already carries all the
new work - the home screen, the tournament hub, the theme picker, the light
mode fix and the ownership rules.

CHECK IT WORKED
===============
Open this in a browser, with ?match= replaced by a live match id:
  https://smartcric.smartstudygrid.workers.dev/?mode=overlay&match=XXXX&style=cyberpunk
  https://smartcric.smartstudygrid.workers.dev/?mode=overlay&match=XXXX&style=luxury
  https://smartcric.smartstudygrid.workers.dev/?mode=overlay&match=XXXX
The three give Default, Cyberpunk and Luxury Dark.
